# Wasteland Survivors 2D (Godot 4.3+)

Открыть: Godot → Import → выбрать `project.godot` → F5.

## Управление
- WASD — ходьба, Shift — бег (тратит выносливость), E — ударить/собрать ближайший ресурс
- 1 / 2 / 3 или Tab — переключение персонажа (остальные продолжают свои задачи)
- Колесо мыши — масштаб камеры
- Нижняя панель: задачи для активного персонажа (рубка, камень, ягоды, чтение, крафт, тренировка перка, обучение у другого за деньги)

## Структура
- `scenes/main.tscn` — корень: World + 3 Survivor + Camera2D + HUD
- `scenes/world.tscn` — карта 1×1 км (1 м = 10 px): Polygon2D земля, Line2D дороги, StaticBody2D границы, деревья/камни/кусты/книги/манекены как инстансы сцен
- `scenes/character.tscn` — CharacterBody2D + CollisionShape2D + Polygon2D + Stats + TaskRunner
- `scenes/hud.tscn` — шкалы, список перков, миникарта (SubViewport с общим world_2d), переключатель, панель задач
- `scripts/perks.gd` — 30 перков; `character_stats.gd` — шкалы/опыт/инвентарь; `task_runner.gd` — автономные задачи
- Слои коллизий: 1 — мир, 2 — персонажи (книги реагируют на слой 2)
- `tools/gen_scenes.py` — пересоздаёт сцены (расстановка объектов); сами сцены можно править в редакторе
